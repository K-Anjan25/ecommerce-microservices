# Archived palette exploration — not current guidance

These files preserve early Cartly visual experiments for comparison and portfolio history. **Every palette in this folder is archived.** In particular, Ink & Violet, neon lime and Forest & Gold were rejected and must not be restored to the platform or WooCommerce theme.

The selected and shipped direction is **Editorial Warmth**:

- cream canvas `#F4F0E8`
- paper `#FBF9F4`
- espresso `#221A16`
- rust action `#A4472D`
- rust hover `#8E3823`
- muted brass `#C8A96B`
- Instrument Serif + Inter + Noto Sans Devanagari

Use [`../tokens.json`](../tokens.json), [`../README.md`](../README.md), and the current [`../wireframes/`](../wireframes/) as implementation sources.

`generate.mjs` exists only to reproduce the historical comparison sheet. Running it does not select or activate a palette.
